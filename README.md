Projects 

Day of Discovery '25-26
In this project, I utilized data from my job to demonstrate the results of the school year. One of these results demonstrate the schools that attended the most field trips. This information is necessary because it demonstrates which schools wanted to attend these trips, but it also showed that our equity can be improved. Additionally, there is data that is provided to demonstrate which sites where able to host the most field trips. Lastly, there is a section that demonstrates the total cancellations and the month that they got cancelled. This demonstrates how some trips were more likely to be cancelled due to the winter rain. However, the data has proved the contrary; it showed that the most cancelled trips were a result of a district wide-strike.
